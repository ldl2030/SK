# MPS-125 DAQ 连续测量修正

日志：`ActivityLog_20261010_164318_164417.txt`。B01/B03/B05/B07 成功，B02/B04/B06 分别超时约 5.1 秒；D01 成功、D02 超时。这些失败发生在 PWM 平均采样之前，所以本次交替故障与平均次数 16→8 无关。C01 采用 CONF + READ? 连续测量，28→32V 点火成功，用时 4.755 秒。

## 改动与问题

上一轮把 MPS-125 单样本读取从统一平均测量辅助方法切换到 `MeasureDaqChannelVoltageAsync`，实际驱动发送 `ABOR`、`*CLS`、`MEAS:VOLT:DC? AUTO,MIN,(@channel)`。该快捷命令在当前实机日志出现交替超时，也没有在成功后显式退出测量状态。

[固纬 DAQ-9600 官方手册](https://www.gwinstek.com/en-US/products/downloadSeriesDownNew/22752/2299) 第 265、281 页明确：自动量程的 resolution 应为 DEF 或省略，AUTO 配 MIN 会产生错误。第 243–246 页说明 ABOR 返回触发空闲状态，READ? 进入等待触发并回传数据；第 358–359 页说明触发次数及源的独立设置。因此 AUTO,MIN 是已确认的命令错误；是否还涉及该台固件的 MEAS? 状态行为，需要读取实机错误队列或复测进一步确认，旧日志没有记录错误队列，不能推断具体错误码。

## 修正

单次电压：测量前 ABOR/*CLS，CONF:VOLT:DC AUTO,DEF，明确 ROUT:SCAN 的目标通道，TRIG:SOUR IMM、TRIG:COUN 1，恢复自动通道延时及批量采样曾关闭的 autozero，关闭单位/时间/通道/报警附加字段，READ? 后无论成功或异常都退出测量状态。

连续点火/逐次平均：仍保持一次配置后重复 READ?；自动量程配置改为 AUTO,DEF，明确单次触发。固定量程保留 MIN 分辨率。批量平均及 K 系列定时扫描保留自身次数与计时方式，不把整段扫描改成单次触发。

电阻读取同样使用 AUTO,DEF、明确通道、单次触发及结束恢复。正向 9.9E37 Ω 的开路过载继续满足 G02 开路最低阻值；NaN/Infinity/格式错误必须失败，通讯失败不再返回虚假 0Ω。电压过载仍拒绝。

未添加逐项 *RST，避免重置功能继电器状态；保持 28V 点火起扫、8 次平均、J 参考复用与精简日志。由程序恢复测量状态，避免现场逐项手工复位。
