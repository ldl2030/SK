## 120点是否有必要

120点是工程诊断选择，不是PDF要求。PDF第58页要求开启等待7000ms、T01/T02原电流范围及关断等待6000ms、T03原±20mA；T02引用放电校准的测量方法，原方法为8读数平均，并注明原仪器trigger 10s、channel delay 0.1s。原文没有明确规定120点、12秒或整周期平均，也没有明确允许约1秒的周期近零状态。替换成GWInstek TIM采样后的方法需经过验证，不可仅因为保留数值限值就宣称与原方法完全等同。

本轮两路均每约6秒出现10个近零点，约1秒低谷；12秒含20个低值，比例16.67%。ST1低谷3.170..4.070s与9.170..10.070s；ST2低谷0.770..1.670s与6.770..7.670s。前后两次日志都支持约6秒规律，但不能据此保证所有板/版本始终同周期，或断言这是正常固件行为。

2秒窗口虽然对本板各起点均能通过，但相位偏差很大。例如导通450mA、每6秒低谷1秒，整周期375mA；含完整1秒低谷的2秒窗口却仅225mA，会误拒绝。导通1300mA同样规律时，整周期1083mA应NG，而含低谷的2秒均值650mA可能PASS。因此不能用当前板的裕量证明2秒方案适用于上下限附近的所有板。

## 建议先落地的较短方案

1. T02/T05固定60点×100ms，采集约6秒；仍在原7000ms等待之后启动，保留1NPLC、1V、真实20.5mΩ和有符号300..1000mA。检查首段/稳态/全窗时序，保留全部低值，不自动重试挑PASS。正式投产前，用多板、不同开始相位及上下限附近工况确认约6秒规律和重复性。
2. T03/T06在原6000ms等待之后固定5点R44×200ms，约1秒；保留原±20mA，所有读数参与。正常流程不固定追加40点外部分流和9条寄存器查询。
3. 关断NG后，保持当前关断工况，在一次预先固定的诊断窗口内读外部分流及R22/R23/R24/R50/R56/R42；诊断仅解释失败，不能改变前面NG为PASS。完整20点/40点仍可作为工程诊断模式。
4. 按本轮耗时，T02/T05各约12.79秒、T03/T06各约5.40秒。短方案预计每板减少约18..21秒，取决于NG诊断是否触发及串口回读耗时。总运行约128秒中还包含电源/治具/报告及安全放电，不能承诺等比例缩短全流程，也不删除安全放电等待。

## 更快但需要额外验证的方向

若需要将6秒采集的新增等待也消掉，可以研究在原7秒等待内并行采集。例如W71=1后先等待约1秒，再在1..7秒采集60点，7秒结束时回读并进行T01/T02判定。该方法改变了原“等待7秒后再测量”的时序；本日志没有1..7秒启动段数据，无法证明此时已稳定。只有证明早期启动稳定、确认周期行为，并认可方法变化后才可采用，不能作为当前已证实正确的推荐默认。

当前最有依据的缩时选择是60点固定窗口加5点关断快速判定；它是待多板验证的工程方案。T06故障解决仍需修复内部补偿路径，单纯减少采样点或延长等待不会把20次一致的49mA变成合格零点。
