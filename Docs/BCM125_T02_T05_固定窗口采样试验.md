## 仪器指令依据

本地 `C:\Users\peanut\OneDrive\Code\Python\SK\ref\万用表-DAQ-9600中文说明书.pdf`：

- 第261–262页：`FORM:READ:TIME ON`、`FORM:READ:TIME:TYPE REL`，每点返回从扫描开始计的相对秒数。
- 第318页：`VOLT:DC:ZERO:AUTO OFF`。窗口期间关闭自动归零，采集结束/失败/取消后恢复 ON。
- 第340–341页：`TRIG:SOUR TIM`、`TRIG:TIM` 为开始到开始的内部定时间隔。若扫描处理时间超过间隔，仪器会连续扫描且不报错。因此除检查120点外，还检查每对时间戳。第一段采用预先固定的±25ms启动容差，后续稳态允许偏差 max(2ms,设定间隔的10%)，100ms设定对应±10ms；首末跨度距11900ms不得超过100ms。超出则窗口无效。启动容差仅用于本测量方法，不扩展其他DAQ调用。
- 第239页：`ABOR` 停止扫描，重新 `INIT` 才会清除旧扫描读数。异常窗口先停止，再查询冻结后的点数及 `FETCH?`，只用于诊断。

## 判定与日志

全部120点参与算术平均，包括3mV多的低谷。读取电流限值仍以源 XML 为准。T02/T05 禁止自动重试选取通过窗口；采样数量不足、非法值、超量程标记、非递增时间戳、实际间隔异常或仪器错误均使窗口无效，不补零、不回退到旧采样方式。

日志保存全部原始电压、相对时间戳和带符号换算电流，每行20点，并汇总平均、中位数、最小/最大、标准差、低/高于限值的点数占比、最长连续低值点数和首末采样跨度。低谷统计暂不新增产品判定限值。连续低值首末采样跨度不是精确跌落持续时间，单个低值点的跨度为0ms；短于积分/采样间隔的事件仍可能被平滑或漏采。

`App.config` 的专用参数：`SKBCM125StringTestSampleCount=120`、`SKBCM125StringTestIntervalMs=100`、`SKBCM125StringTestRangeVolts=1`、`SKBCM125StringTestNplc=1`。不修改其他章节的平均参数。

T02完整100点的首段为83ms，后续为99..101ms；当前首段75..125ms独立校验保留该读数。后续仍按90..110ms、全窗累计偏差不超过100ms校验，禁止丢弃首点或对NG临时放宽。T02/T05改为120点以覆盖本轮约6s变化的两个周期，全部近零读数继续参与平均。

T03/T06在原6000ms关断等待后，读取20点R44，每200ms按请求开始时刻安排，窗口4s。请求不得超出预定时隙，通信使用当前连接的一次事务，失败不重读、不重新枚举、不切换REMOTE。调度迟到不得超过50ms；每次回复须在该200ms时隙内完成。缺点、非有限值或时隙超时使整窗无效，不使用部分均值。所有读数保持符号；正式结果仍是原R44全样本均值与±20mA比较。

同一时间段另以DAQ内部100ms定时获取40点分流诊断；记录全部原始值、独立时间戳和平均/极值。该诊断不替代R44判定。窗口前读R42/R50/R56与R22/R23/R24，窗口后读R42/R50/R56，均为只读、不改补偿参数。DAQ和MBD时间轴起点独立，不能声称逐点精确同步。

窗口取消/失败后，先取消并等待DAQ采集与恢复任务结束，才允许进入下一步。未完成的诊断不能补零或用于PASS。持续+50mA的T06仍应NG；该版本用于改善测量一致性和定位，不修正DUT内部零点。
