# BCM125 章节命令归属与电源矩阵

## 范围与判定依据

- 原始规程：`19BU03_119 TESTING PROCEDURE BCM UP125 BOARD rev_5_EN.pdf`（Rev.5）。章节 7-27 位于 PDF 第 14-61 页；固件表在第 6 页，MBD/PC 通信架构在第 9 页。
- 本文按 **测试 PC 实际下发命令时所在终端** 分类，而不是按信号最终来自哪块板分类。`RxxVERB` 与同号 `Rxx` 属于同一终端；`VERB` 只改变返回展示，不改变命令归属。
- 电源名称：**ANS**=电源 C，经 Y7/RL4 给 MPS/DUT；**VBUS**=恒辉源 A；**String**=恒辉源 B；**负载**=KUNKIN 7303。DAQ 指 DAQ960/万用表路径。

## 固件、终端与命令速查

| 会话位置 | 路由命令 | 命令由谁处理 | 代表用途 |
|---|---|---|---|
| MBD Main MCU 终端 | `EXIT` 后 | MBD Main MCU | `W86` 复位、MPS 继电器/模拟输入控制、MBD 状态读取、内部 CAN 诊断 |
| BCM1 / String 1 DUT MCU | `REMOTE1` 后 | BCM U56 应用固件 | String 1 的 `Rxx/Wxx/ACT->FLASH` |
| BCM2 / String 2 DUT MCU | `REMOTE2` 后 | BCM U91 应用固件 | String 2 的 `Rxx/Wxx/ACT->FLASH` |
| BCM1/BCM2 Bootloader | TTL + 各自 BOOT0 + RESET | DUT Bootloader | Chapter 9 对两颗 BCM MCU 的擦除、下载、校验 |
| SAFE 节点 | 本规程无独立 `REMOTE` 入口 | 当前仅由 MBD `R15` 间接观察 | SAFE 内部 CAN 从机响应时间；不是 PC 对 SAFE 的直接 `R/W` |
| 诊断模式 | `DIAG ON` | 当前所在终端 | `EXIT` 后为 MBD；`REMOTE1/2` 后分别为 BCM1/BCM2 |

固件表原文（PDF p.6）：BCM U56=`BCM_125_V8.HEX`，BCM U91=`BCM_125_V8.HEX`，MBD U9=`MBD_125UP_222.HEX`，MBD U13=`SAFE_UL_V2_NOLOCKEEPROM.HEX`。因此 SAFE 位于 MBD 的 U13，而非两颗 BCM DUT MCU。

## 命令方向：谁发给谁

| 场景 | 方向 | 应记录为 |
|---|---|---|
| MBD 本地命令 | 测试 PC → USB 虚拟 COM → MBD Main MCU | PC 发给 MBD；MBD 执行/回读。如 `W86`、`W94`、`W95`、`R14/R15/R81`。 |
| BCM1 命令 | 测试 PC → MBD CAN 桥 → `REMOTE1` → BCM U56 | PC 经 MBD 路由给 BCM1 DUT MCU；BCM1 执行/回读。 |
| BCM2 命令 | 测试 PC → MBD CAN 桥 → `REMOTE2` → BCM U91 | PC 经 MBD 路由给 BCM2 DUT MCU；BCM2 执行/回读。 |
| 烧录 | Flash 工具 → TTL → BCM U56/U91 Bootloader | 烧录器向各 DUT Bootloader 发协议；MBD 只用 `W86` 和复位链路辅助。 |
| SAFE 监测 | SAFE → 内部 CAN → MBD；PC 以 `R15` 查询 | MBD 读 SAFE 上报状态，不能写成 PC 直接向 SAFE 发命令。 |

## 电源使用总表

| 电源/负载 | 主要章节 | 用途 |
|---|---|---|
| ANS（电源 C） | 08-27 | 经 Y7/RL4 给 MPS 及 BCM 双 MCU 供电；故障时先关输出再断 RL4 |
| VBUS（源 A） | 09、18、19、23-26 | VBUS、中点、预充、VSTR_NEG 与 CCB 模拟 |
| String（源 B） | 09、16、20-26 | 两串 VBATT/放电/充电与 String test 模拟 |
| KUNKIN 7303 | 09、20-26 | 模拟 String 负载、放电及 CCB 受载 |

## 安全与归属边界

1. String 输出前必须先确认源 B 输出 OFF，再闭合所需高功率继电器；结束时先关输出再断路径。
2. ANS/RL4 断电顺序：先关 ANS 输出，后断 Y7/RL4；任何章节失败均应安全断电。
3. `W86/W94/W95/R14/R15/R81` 在 **MBD** 会话；`R/W/FLASH` 在 `REMOTE1` 或 `REMOTE2` 后分别属于 BCM1/BCM2。
4. `R15` 不证明 SAFE 有独立可写协议；它只是 MBD 读取 SAFE 内部 CAN 从机响应时间。
5. Chapter 9 的 TTL/Bootloader 链路与运行期 USB-B→MBD→CAN→Remote 链路不同，不能互相替代。
