# BCM125 R09 / R23 电流零点偏差分析

本报告仅进行日志、规程和本地固件文件的离线分析；没有进行仪器控制，没有修改测试限值、应用流程或 DUT 固件。

## 结论及证据边界

R09 / R23 的 NG 判定符合原始 PDF。它们检查的是充电电流校准之后，在 15V 共模条件下的零电流误差，不是检查尚未补偿的原始 ADC 零点。PDF 明确允许原始电流 ADC 随 VSTR_NEG 变化，并专门要求计算、写入电压交叉补偿系数 W24。

三次日志呈现稳定的电压相关偏置。校准数据计算出的“没有加入 W24 时的电流”几乎直接复现 R09 / R23；同一批数据加入 W24 后则接近零。这把首要问题定位到 DUT 的 R44 电流计算 / 电压补偿链路。

本地实际烧录的 BCM_125_V8.hex 静态检查进一步发现：R44 的计算路径使用 W22、W23，经滤波后输出，未发现 W24 参与该路径。这是具体的固件实现线索，不只是通过日志猜测。仍应通过固件源码审查和 DUT 参数读回核实现场版本及参数持久化，以最终关闭问题；现有日志没有 R22/R23/R24 校准参数的读回，写命令返回 OK 本身不能证明计算已经使用这些参数。

此处“R23 测试项”与“R23 寄存器”含义不同：测试项 R23 实际发送的是 R44；寄存器 R23 读回的是 offset_iccb。

## PDF 到底要求什么

PDF 第46~50页为充电电流校准：

1. 低压工况实际设 VBUS=1V；表格中的“0V”是规程使用的名称。读取 R50 / R56 四次平均，并测外部分流零电流。
2. VBUS=15V、零电流，等待2000ms，读取 R50 / R56 四次平均。
3. 低压、约6A，获取电流 ADC 和外部分流电流，计算电流增益。
4. 第49页计算电压交叉补偿 gain_iccb_vstr_neg，以及包含该项的 offset_iccb；第50页写 W22、W24、W23，并 ACT->FLASH。

第51~53页进行校准后的四工况验证。第52页第37步读取 R44，对应 R09。第53页要求第二路重复流程，对应 R23；第66页再次明确第二路限值。

| R09 | ST1 R44，15V / 0A | -20~20mA，第53、65页 | -20~20mA |
| R23 | ST2 R44，15V / 0A | -20~20mA，第66页 | -20~20mA |

R09 / R23 的单位是 mA，实际命令为 R44；不是 R56 的 ADC count，也不是安培。串口直接返回 `044 = -23` / `044 = 138`，解析后数值与日志保存一致，没有把寄存器编号044误当成测量值。

规程允许零电流 ADC 在1350~1550 count内变化。这不等于校准后的电流可以有几百mA偏差：宽 ADC 范围是校准输入窗口；±20mA是校准后的验收范围，二者没有冲突。

±20mA约等于本次增益下的4.6个电流 ADC count，或6A的0.33%。对于已经做零点和电压补偿的通道，目标在工程上有依据；但仅凭这一个样品的日志，不能证明整个生产系统的测量能力、温漂及批量良率已经满足该目标。若要重新制定规格，需要测量系统分析和多板统计，不能依靠给这块板放宽范围。

PDF 其他行存在不一致：第53页 R02 为±40mA，而第65页汇总上限印为400mA；第二路 R16 汇总为-10~17mA；R26 汇总比第一路更窄；部分百分比注释与数字不符。这些应与规程所有者确认，但 R09 / R23 的±20mA在相关表格中一致，没有据此扩大的依据。

## 校准数据怎样解释这两个偏差

将 PDF 第49页关系写成理想静态模型：

```text
I_mA = (G × ADC14 + K × ADC0) / 4096 + O
G = gain_iccb            → W22
K = gain_iccb_vstr_neg   → W24
O = offset_iccb          → W23
K = -G × (ADC14_high - ADC14_low) / (ADC0_high - ADC0_low)
O = -(G × ADC14_low + K × ADC0_low) / 4096
```

这个模型用于检查系数的作用及偏差数量级。实际固件还包含参考电压归一化、滤波和整数转换，日志读取亦非同时采样，因此不要求逐mA完全一致。

| 10:55运行的校准量 | ST1 | ST2 |
|---|---:|---:|
| ADC0，低压零电流 | 44.5 | 44.5 |
| ADC0，15V零电流 | 675 | 672 |
| ADC14，低压零电流 | 1428 | 1416 |
| ADC14，15V零电流 | 1422 | 1446 |
| G，W22 | 17617 | 17730 |
| K，W24 | 168 | -848 |
| O，W23 | -6144 | -6120 |

原始 ADC14 的四次平均样本在上述零点均无抖动：ST1 低压4次全1428、15V全1422；ST2低压全1416、15V全1446。校准过程并没有在明显不稳定的 ADC 上取平均。

## 固件离线证据

源配置与bin/Debug运行配置中的BCM_125_V8.hex SHA256相同：

```text
A189711CB9F374B4B39E10E1A0D3F19A67C68EC90451E416CD405F7F63166ED7
```

10:55日志记录此运行路径用于C01、C02，两颗MCU烧录并验证通过。静态分析针对这个文件，不是推测另一个版本。

固件参数描述表中：

| 参数 | 描述表地址 | RAM地址 |
|---|---|---|
| 22 gain_iccb | 0x080096C0 | 0x200005E4 |
| 23 offset_iccb | 0x08009714 | 0x200005E8 |
| 24 gain_iccb_vstr_n | 0x08009768 | 0x200005F4 |
| 44 iccb | 0x08009DF8 | 0x20000700 |

电流计算路径：

- 0x08004E2A读取参数基址0x200005C4+0x20，即W22；随后对电流ADC进行增益和参考电压归一化。
- 0x08004E58读取同一基址+0x24，即W23，将其加到电流结果并保存。
- 0x0800507C~0x080050B8对该电流结果滤波，存到中间结构0x20000AD4+0x34。
- 0x08007BEE~0x08007C00读取该中间结构+0x34，转换整数，写到R44对应的0x20000700。
- 这条计算、滤波、发布路径没有读取W24对应的基址+0x30，也没有加入电压ADC乘W24的项。

因此“W24可以写入且返回OK”与“R44确实使用W24”是两个不同条件；只检查命令成功无法验证后者。

## 程序与PDF的差异是否解释问题

- 校准公式、W22/W24/W23的写入顺序与PDF一致，数值重算一致。
- 校准时15V等待2000ms，验证时15V等待1000ms，都对应PDF。重复运行结果稳定，优先级低于已匹配的补偿缺失证据。
- 程序在CH24由6A切回0A时额外发送W69=1关闭CCB；PDF第32步只设String=0V/0A，直至第47步才关闭CCB。该差异需要在完整流程一致性检查中记录，但当前校准零点同样是CCB OFF，不构成“校准OFF、验证ON”的工况不一致，也不能解释为何偏差恰好等于缺失的W24项。
- 当前程序参数写入只检查命令成功，未在该写步骤读回对应R寄存器。日志也没有重新上电后的系数读回，故参数应用/保存问题尚有一个验证缺口。
- DAQ分流计算使用现场配置0.0205Ω；PDF明确写“使用真实治具阻值”，其示例约0.02159Ω不能直接替代现场值。真实阻值应以治具标定记录确认。阻值选错会影响外部6A结果及G，但不能合理解释R09/R23零电流偏差恰好与电压补偿项对应。

## 新日志的其他失败项

CH26第二路T04=+20mA，但外部分流T05=+858.886mA，String电源回读44.839V/0.886A。T06关断后R44=50mA，而DAQ115压降0.29µV，对0.0205Ω仅约0.014mA。

T06说明在这个工况下也存在“板内显示电流，但外部分流几乎没有电流”的测量偏置。T04的板内/板外差距更大，不能仅用CH24的138mA常数解释；应单独核对50V条件下电流采样的共模行为、反向电流测量及内部分流实际通路。外部已有约0.86A，不支持简单认定为MOS完全没有导通。现有日志不足以定位到具体运放、电阻、针位或继电器触点。

## 解决方向

1. 保留R09/R23的±20mA，保留原始测量与NG结果。当前不具备放宽规格的证据。
2. 审查BCM125 V8的iccb计算源码：将PDF要求的电压交叉补偿纳入计算；与ADC0、电流ADC的归一化方式保持一致；确认补偿在滤波和报告输出之前作用，且充电控制所用电流与R44一致。不能只修串口显示而遗漏控制环。
3. 通过既有程序/后续日志记录两路R22、R23、R24读回；分别核对写后与断电重启后的值，以排除参数应用和持久化问题。此报告没有发出任何现场读命令。
4. 使用确认后的固件重新执行CH23校准及CH24四工况验证。确认高压零点、低压零点与两种6A工况同时通过；避免用调offset的方法使15V归零而损坏低压零点。
5. CH26第二路单独定位内部电流采样/实际通路，不能把T04/T06都归并为同一个常数零点偏置。

没有固件源码或经确认的修正版文件时，不能宣称DUT已修复；本次完成的是规程核对和问题定位。
