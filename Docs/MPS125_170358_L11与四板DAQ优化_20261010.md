# L11 电流解释与四板 DAQ 统一

依据日志 `ActivityLog_20261010_170358_170925.txt`。

## L11 测量及阻值

L11 是 PWM2 开启时的 VBUS 总吸收电流，来自物理 CH17/DAQ117 的外置分流电阻压降。`Mps125StationMap.VbusShuntOhms=1.0`，动作类型 DaqShuntCurrent，公式为 `I(mA)=V(V)/R(Ω)×1000`。日志原始读数 `+1.03631010E-01 V`，即 103.631010mV，按 1Ω 换算为 103.631010mA。它不是 R71，也不是 DAQ108 的 FBK_2 电压，更不是单独测出的加热电阻电流。

现有站点映射注明两类不同电阻：VBUS 电流分流电阻 1Ω；加热器模拟电阻 2.2kΩ/50W。必须区分。

L04 关闭加热器时分流原始读数为 43.4071503mV，得到基线 43.4071503mA。L11 比基线增加约 60.2238597mA。采用本轮 DAQ113 参考 137.312014V，并假设负载两端电压近似 VBUS、板子自身基线不变，则 PWM2 负载等效阻值约为：

`137.312014 / ((103.631010-43.4071503)/1000) = 2280.03Ω`。

这约比名义 2.2kΩ 高 3.64%，是负载支路的粗估等效阻值，不能证明某一只实体电阻为 2280Ω；开关压降、控制电路附加电流、VBUS 随时间变化和分流阻值误差均未独立测量。直接用总电流得到的约 1325Ω 是整板等效负载，也不是分流电阻阻值。

若按名义 2.2kΩ 估算，137.312V 下负载电流约 62.415mA，再加 43.407mA 基线，总计约 105.822mA。因此即使负载恰好为名义 2.2kΩ，当前 50–100mA 的 L11 范围也可能将正常总电流判失败。该现象应复核判定范围是否对应“总电流”及当前夹具负载，不宜以稳定 103mA 为依据修改换算电阻来使结果通过。

无法仅由同一分流压降及其计算出的电流反推出实际分流阻值。假设真实电流恰为 100mA，则需 `0.103631010/0.100=1.0363101Ω`；这只是条件计算。需要断电、隔离并用四线法量分流电阻，或获得独立且精度足够的电流参考，再按 `R=Vshunt/Ireference` 校准。此次保留现有 1Ω 与 L11 范围，不改用户判定标准。

## 本次代码优化

四板型 BCM-125/BCM-250/MPS-125/MPS-250 共用 `MeasureDaqChannelVoltageAsync`。完善旧 `MeasureDaqVoltageAsync`，也使用明确通道配置、单次触发、READ?、成功/异常结束恢复与严格无效值拒绝；统一所有板型，禁止异常返回虚假 0V。自动量程用 AUTO,DEF，固定量程保留传入值，结束不执行 *RST。

统一平均方法的一个样本分支直接调用该单测方法，MPS-250 和 BCM 的单点调用也得到相同恢复行为，省去逐次平均的框架。多点平均、BCM 的固定窗口、MPS K 系列窗口保留自身的完整样本与时长。

普通批量平均最初的保守等待从 `N×interval+250ms` 改为 `(N-1)×interval+margin`，margin 至少 100ms，并覆盖两次 NPLC 积分时间。之后仍查询 DATA:POIN?，必须达到预期完整点数才回读，不足时继续等待原超时限制。默认八点/三点、100ms、NPLC=1，每批理论少等 250ms，本轮 24 批约可再省 6 秒；尚待新实机日志验证。没有进一步降低采样次数或缩短必要稳定窗口。

完整编译、四板模拟和故障清理验证，并用带状态的驱动替身检查自动/固定量程、严格解析、扫描切换、超时恢复。真实四板硬件应用仍应逐板复测，模拟不能替代实机确认。
