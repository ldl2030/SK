# MPS250 章节命令归属与电源矩阵

## 范围与判定依据

- 原始规程：`19BU03_012 TESTING PROCEDURE MPS UP250 BOARD rev_3_.pdf`（Rev.3）。测试序列为 Chapter 6-17（PDF p.10-19）。
- 与 BCM 系列不同：PDF 在 Chapter 9、10-17 均写明 `EXIT` 是“ensure access to the **DUT MCU terminal**”，串口为 DUT 直连 115200 8N1。故本流程中的普通 `EXIT/DIAG ON/Rxx/Wxx` 默认由 **MPS250 DUT MCU** 处理，不应误标为 MBD 命令。
- 只有 Chapter 17 明确写出 `REMOTE 31` “access the micro **SAFE terminal**”；紧随其后的 `W38=0` 才属于 SAFE。

## 终端与命令速查

| 会话位置 | 进入方式 | 命令由谁处理 | 代表命令 |
|---|---|---|---|
| MPS250 DUT MCU 终端 | 上电后串口；`EXIT` 确保回到 DUT | MPS DUT MCU | `R0/R68/R69/R70/R71/R78/R79/R81/R357`、`W89/W91/W92/W95/W96/W99/W100/W101` |
| MPS250 DUT 诊断模式 | DUT 终端执行 `DIAG ON` | MPS DUT MCU | 诊断读写权限 |
| SAFE MCU 终端 | `REMOTE 31` | SAFE MCU | Chapter 17 的 `W38=0`（`safe_risc_shut_down` / `risc_on`） |
| 外部仪器/夹具 | PC 经串口分别控制源、DAQ、继电器 | 仪器或夹具，不是 DUT 命令 | VBUS/VBATT 设置、RELAY_1-6、DAQ 测量 |

## 命令方向：谁发给谁

| 场景 | 方向 | 应记录为 |
|---|---|---|
| DUT 普通读写 | 测试 PC → DUT 串口 → MPS MCU | PC 发给 MPS250 DUT MCU；DUT 执行/回读 |
| SAFE 加热器保护 | 测试 PC → DUT 串口 → `REMOTE 31` → SAFE MCU | PC 经串口路由到 SAFE；仅 `W38` 有该明确证据 |
| DUT 响应 | MPS DUT MCU → 串口 → 测试 PC | DUT 回传 `Rxx` 值；不是 DUT 主动下发测试命令 |
| 仪器控制 | 测试 PC → 电源/DAQ/继电器串口 | 外部仪器执行，不属于 MPS/SAFE 固件 |

## 安全与归属边界

1. 每次 VBUS/VBATT 接入前保持相关继电器状态与源输出一致；结束均先关源，再打开路径继电器。
2. `EXIT` 在本 MPS 规程中不是 MBD 会话切换，而是回到 **DUT MCU terminal**；因此 `W91/W95/W101` 不能沿用 BCM250 的 MBD 分类。
3. `REMOTE 31` 是唯一有原文证据的 SAFE 入口；仅 Chapter 17 的 `W38=0` 属 SAFE。之后必须 `EXIT` 后再用 DUT 命令。
4. DAQ 的外部读数和 DUT `Rxx` 内部 ADC 读数是不同证据源，不能相互替代。
