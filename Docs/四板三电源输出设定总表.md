# BCM/MPS 四板三电源输出设定总表

范围：BCM-125UP、BCM-250UP、MPS-125UP、MPS-250UP 的**三台可编程电源**。同一设定在多个章节重复出现时只列一次；

| 电源 | BCM-125UP | BCM-250UP | MPS-125UP | MPS-250UP |
|---|---|---|---|---|
| A（恒辉 1） | VBUS 模拟源 | VBUS 模拟源 | VBUS 主供电 | VBUS 主供电 |
| B（恒辉 2） | String 发生器 | String 发生器 | VBATT 模拟源 | VBATT 模拟源 |
| C（ANS） | MPS/BCM 主供电，经高功率 **Y7/RL4** | MPS/BCM 主供电，经高功率 **Y7/RL4** | 不使用 | 不使用 |

> `I` 是电源的输出限流设定，不等于 DUT 实际消耗电流；实际电流仍以规定的分流电阻/DAQ 测量为准。`OFF` 必须先执行，再闭合或打开高功率路径继电器。

## 电源 B 的原文名称：BCM 与 MPS 不可混叫

| 板型 | PDF 对电源 B 的设备名称 | PDF 的章节动作名称 | 被模拟/送入的对象 | 正确记录名称 |
|---|---|---|---|---|
| BCM-125UP | `power supply for string voltage simulation`（p.4、p.14） | `String voltage generator` / `VSTRINGA`（p.9、p.35 起） | String 电压/电流；IG1、VSTRING NEG 等测试网络 | **String 发生器（VSTRINGA）** |
| BCM-250UP | `power supply for string voltage simulation`（p.4、p.14） | `String voltage generator` / `VSTRINGA`（p.9、p.33 起） | String 电压/电流；IG1、VSTRING NEG 等测试网络 | **String 发生器（VSTRINGA）** |
| MPS-125UP | `power supply to simulate battery voltage`（p.3、p.9） | `VBATT simulator`（p.16、p.17） | VB+/VB2+/VS_PREC，以及经 RELAY_6 到 ISOBATT_INPUT J7.5 | **VBATT 模拟器** |
| MPS-250UP | `power supply to simulate battery voltage`（p.4、p.10） | `VBATT simulator`（p.16、p.17） | VB+/VB2+/VS_PREC，以及经 RELAY_6 到 ISOBATT_INPUT J7.5 | **VBATT 模拟器** |

BCM Chapter 16 的标题虽含 `VBATT_SCAL_IN`，但该章是读取 BCM 输入信号、由 MBD 控制 MPS RL1/RL2 的校准；它**不是**“电源 B=VBATT 模拟器”的 MPS 测试。BCM 电源 B 应始终按 String/VSTRINGA 记录。反过来，MPS 的 VBATT 模拟器在 DUT 寄存器中可能测到 `vstring+`/`vstring2+`，也不应因此改名为 String 发生器。

## 使用时的三条约束

1. BCM 板：ANS 必须遵循 **先关输出，再断 Y7/RL4**；String（电源 B）必须在输出 OFF 时先闭合 **Y1+Y3+Y6**，关断时反序。
2. MPS 板：VBATT（电源 B）必须在输出 OFF 时先闭合高功率 **Y1+Y9**，输出关闭并确认放电后才可打开；逻辑 RELAY_6 是 DAQ `@304`，不能替代 Y1/Y9。
3. 电源 A 的各项电流是限流值；所有“电流测试”仍须按规程读取 1Ω、20mΩ 或规定外部分流的 DAQ 电压后换算。
