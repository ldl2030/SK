## 范围修正

| 结果 | 原范围 | 新范围 | 日志证据 |
|---|---|---|---|
| F09 / R357 低态 | 0–100 Count | 0–0 Count | `357 = 0` |
| F10 / R357 高态 | 3900–4096 Count | 1–1 Count | `357 = 1`，原范围把逻辑电平当成 ADC 高态 |

G02 采用与 MPS-250 一致的开接点判定：至少 1MΩ，没有上限。用户已确认该次 G02 应通过。`9.9E37` 按本次断开接点工况解释为电阻超量程/开路指示，不作为可溯源的实际电阻值；通信异常仍不能转换为通过。DAQ-9600 的电阻超量程状态见 [厂家用户手册的 Resistance Overload 定义](https://www.gwinstek.com/en-US/download/downloadFile/22752)。这不改变电压采样对超量程读数的拒绝规则。

源配置是 `ProjectConfig/SK/MPS-125/MPS-125_autoTest.xml`。本板目录没有独立的 PSV 客户报告模板，范围由 XML 的 UI/通用结果配置提供。

## J05/J07 超时根因与修正

15.15 可见行已经成功测得 DAQ113 参考电压 `137.314536 V`，旧实现丢弃该值，J05–J08 又分别重新查询。J05/J07 因重新测量超时而异常，J06/J08 重新测得约 137.314 V 后通过。因此无需改变 MPS-125 的增益范围 `200000–205000 Count`，也不能复制 MPS-250 的 `400000–410000`。

采用 MPS-250 的参考值复用方式：

- 15.15 存储成功的、有限的、正值 DAQ113 参考，单位为 V，键为 `MPS125.CALIBRATION.VBUS_REFERENCE`。
- J05–J08 的 XML 依赖同时包含相应 ADC 结果及 `MPS125.CH15.S016.ACTION`。
- 四个增益仅计算 `4096 × 参考电压(V) × 1000 ÷ ADC`，不再查询 DAQ。
- 第 15 章 VBUS 重新设定、爬升或参考测量重试前清除旧参考；缺失、失败、零值、非有限值或超量程参考阻止计算。
- 参考测量是供电相关关键行；原来的继电器、电源顺序和 231 行保持一致。

复算本轮 ADC `2782/2783/2783/2783`，预期 J05 约 `202171.222`、J06/J07/J08 约 `202098.577`，均处于本板原增益范围。

验证：全解决方案 MSBuild；MPS-125 结构检查、无连接的硬件模式日志数据复算、无效/旧参考拒绝、完整模拟和故障收尾；MPS-250 模拟回归。未执行实际硬件复测。
