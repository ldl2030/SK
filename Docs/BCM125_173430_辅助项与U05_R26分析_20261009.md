# BCM125 173430：辅助项、U05 和 R26

日志：`bin/Debug/Logs/ActivityLog_20261009_173430_174358.txt`。本轮 F01、R20 和 CCB 功能/关断均已通过；新增的非 R44 失败主要是 18.8、两路 24.26 等待和 U05。

## U05 的回读确实不一致

ST2 写入：`W40=09/10/2026 17:43`，设备回应 OK；ACT->FLASH 也返回成功。

17:43:45.872 的 R40 回读：`040 = 09/10/2026 1W40=09/`。这不是正常的日期，时分部分混入了 W40 命令文本。程序解析出的实际字符串就是 `09/10/2026 1W40=09/`，与写入值严格比较不一致，原 U05 判失败有依据。ST1 的 U02 则完整返回 `09/10/2026 17:43` 并通过。

这份日志只有一次异常 R40 回读，无法区分临时串口/转发干扰和 MCU 保存字符串损坏，不能认定为“日期正常但解析器误判”。本次增加一个有限的只读复核：

- R40 日期符合格式且与写入值相等：直接通过。
- 日期格式异常：等待该 U02/U05 XML 行的 DelayMs=200，再读 R40 一次。
- 第二次完整匹配才通过，显示 `1 (re-read verified)`；仍异常或不相等则 FAIL，并记录写入值和最终读回值。
- 合法格式的错误日期仍直接失败；序列号校验保持严格比较。
- 复核不发送 W40、不发送 ACT->FLASH、不截断异常字符串，不用预期内容替代设备回读。

若下一轮仍出现相同乱码且复核也失败，应查 MCU 日期缓冲区长度、命令缓冲区复用和转发时序。当前信息不足以直接修改固件。

## 24.26 不再因等待超时造成产品 NG

上次修改把 String 电源等待传成了 `STRING`，而设备读取函数只支持 ANS、VBUS、SECONDARY 和 LOAD，导致两路连续输出 `Unknown power domain: STRING`。这属于测试程序接口使用错误，并不说明电源 5 秒内真的未稳定。

本次改为读取实际 String 电源对应的 SECONDARY，并明确两路 24.26 是辅助等待：

- 就绪提前结束；到 XML 的 5000ms 上限仍未就绪，显示黄色“警告”，测量值栏记 `TIMEOUT, continued`，直接进入下一行。
- 辅助超时不进入失败重测、不触发整机 NG、不调用普通失败后的断电策略。
- 其余必须满足的电压稳定检查仍保持原失败处理，供电和继电器动作失败没有转成警告。

10V/6A 是电源设定；负载进入恒流工作时实测电压可能达不到设定电压。因此此处的电压等待也不能替代后续正式电流/电压验收。

## 18.8 的处理

初始 R68=57，高于辅助观察范围 0–49。后续 L01–L08 全部 PASS。PDF Rev.5 第29页确实写了以 R68<50 验证 C21 放电，因此 57 不应伪装成“已满足原放电范围”。

按照本次对辅助行的处理要求，只调整初始 `BCM125.CH18.S008.R68` 对总结果的影响：保留原始读数及参考范围，超限显示黄色“警告”，不单独把产品判 NG。观察值正常则正常完成；后续 L01–L08 仍严格按原 XML 判断。通信响应无效、继电器/供电/安全动作失败、清理未完成仍是失败。这不是把所有 ACTION 行或所有 R68 行的失败统一忽略。

共用执行结果增加 Warning 状态，表格显示“警告”，章节进度把它计为已完成并保留章节警告；全部正式结果通过且清理完成时，总结果可以 PASS。辅助行不会被涂成普通测量 PASS。此次没有更改 0–49 数值范围。

## R26 更符合电压交叉补偿没有生效

| ST2 工况/参数 | 本轮数据 |
| --- | --- |
| 低压零电流 R16 | 10mA |
| 低压约6A R19 / 外部分流 R20 | 5970mA / -5962.313mA |
| 15V 零电流 R23 | 141mA |
| 15V 约6A R26 / 外部分流 R28 | 6104mA / -5960.352mA |
| R26 与外部分流绝对值之差 | 143.648mA |
| Q30/W22 电流增益 | 17735 |
| Q31/W24 电压交叉补偿 | -862 |
| Q32/W23 电流 offset | -6118 |

R26 此前已经等待 2000ms；外部分流仍在正常范围。高压零点的 +141mA 与高压6A的约 +144mA 接近，低压6A误差只有约 8mA。这种误差随电压工况变化的模式不能简单归因于等待不足。

更直接的离线复算：本轮 15V 零电流校准的 ADC14=1445.5、ADC0=671。根据现有校准模型：

```text
不计W24：17735 × 1445.5 / 4096 - 6118 = 140.775mA
计入W24：(17735 × 1445.5 - 862 × 671) / 4096 - 6118 = -0.436mA
实测R23：141mA
```

且本轮 T06 后的只读诊断已读回 R22=17735、R23=-6118、R24=-862，与本轮写入值一致。这证明参数能被读回，但不能证明 R44 计算真的使用了 W24。现象与此前 `BCM125_R09_R23_电流补偿分析_20261009.md` 中的本地固件静态分析线索一致：优先检查固件 R44 的电压交叉补偿路径。

R26 的原规程/源 XML 范围为 5920–6080mA，6104mA 超上限 24mA。此次不改该范围、不减去 R23、不用外部分流替换 R44，也不修改 HEX。固件缺陷需要源码和实际计算链路确认后处理。
