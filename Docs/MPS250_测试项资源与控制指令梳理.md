# MPS-250UP 测试项资源与控制指令梳理

## 依据

- 客户资料：`19BU03_012 TESTING PROCEDURE MPS UP250 BOARD rev_3_.pdf` 的提取清单，见 `Docs/MPS250_PDF_ACTION_AND_CONFLICT_MANIFEST.md`。
- 代码/配置：`Mps250DetailedActionCatalog.cs`、`Mps250StationMap.cs`、`ProjectConfig/SK/MPS-250/MPS-250_autoTest.xml`。
- 本板仅需要 VBUS、VBATT、DAQ、USB-B/夹具；不使用 Ans、电源 C、电子负载和 TTL 烧录。

## MPS-250 特殊约束

- MCU 主开关只有 `W101`；`W99/W100` 是两路加热 PWM，DI9/DI10 仅是夹具反馈，不能替代 MCU 控制命令。
- 第16章：B 输出关闭、零压/小电流读回门禁未通过时，不可闭合 `@304` 或升至 250V。
- 第17章任一 R71、FBK 或电流安全结果失效，必须先关闭加热和所有电源再处理后续动作。
- 释放夹具/急停后 USB-B 会机械断开；清理行应标记 MBD 命令已跳过，仍必须完成电源与继电器断开。
