## 恢复策略

仅 BCM-125 的 EXIT 和空命令通信检查启用恢复。连续两次识别失败时，每次命令恢复周期最多执行一次根终端恢复；恢复只使用本设备实例通过协议验证过的端口，不使用配置口或跨测试历史口授权操作，并排除仪器及 TTL 串口。

在该端口最多发送两次 EXIT。必须先确认完整 EXIT 回包，再发送 0D，收到 COMMAND ERROR 且回包末尾为 Ready 才保留连接、重发原命令；否则关闭句柄并按原逻辑判失败。初始化和释放设备时清除本次协议验证记录。

EXIT 非空回包含 COMMAND ERROR 与 Ready 但校验不通过时，在当前连接重新发送一次 EXIT，不放宽回包完整性判断。

EXIT 的含义是返回 MBD 根终端，不等同于 DIAG OFF。没有协议依据时不自动发送 DIAG OFF，也不对其他端口广播退出命令。REMOTE 状态下的读写与校准恢复继续由既有终端状态机负责。
