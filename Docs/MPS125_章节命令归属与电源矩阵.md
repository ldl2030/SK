# MPS125 章节命令归属与电源矩阵

## 范围与判定依据

- 原始规程：`19BU03_020 TESTING PROCEDURE MPS UP125 BOARD rev_3__.pdf`（Rev.3）。测试序列为 Chapter 6-17（PDF p.9-19）。
- 现场安全裁决：仅 Chapter 15 在切换 Relay_5 后恢复 VBUS 时使用`25→50→75→100→125→137.5V`六级缓升，每级固定等待200ms、不做稳定检查；Chapter 7/9/10 按原规程直接上137.5V。
- 规程把 `EXIT` 明确描述为进入 **DUT MCU terminal**，正常串口为 115200 8N1。普通 `EXIT/DIAG ON/Rxx/Wxx` 全部归 **MPS125 DUT MCU**，而不是 MBD。
- Chapter 17 唯一明确的 SAFE 会话是 `REMOTE 31`；`W38=0` 由 SAFE 处理。退出后再 `EXIT/DIAG ON`，`W99/W100/W92/R71` 回到 DUT MCU。

## 命令方向：谁发给谁

| 场景 | 方向 | 正确分类 |
|---|---|---|
| 普通 MPS 命令 | 测试 PC → DUT 串口 → MPS125 MCU | PC 发给 DUT MCU，DUT 执行/回读 |
| SAFE 加热器关断 | 测试 PC → DUT 串口 → `REMOTE 31` → SAFE | PC 路由给 SAFE；只有 `W38` 有明确 SAFE 证据 |
| DUT 响应 | DUT MCU → 串口 → 测试 PC | DUT 回传 `Rxx`，不是 DUT 主动向 PC 下发命令 |
| 仪器动作 | 测试 PC → 电源/DAQ/继电器 | 外部设备动作，不属于 MCU 固件 |

## 安全与归属边界

1. VBUS/VBATT 输出开启前先确认相关继电器路径；结束先关源，后断开继电器。
2. `EXIT`、`W91`、`W94`、`W95`、`W101`、`W295` 在本规程都属于 **MPS125 DUT MCU**；不能套用 BCM 板中 MBD 的同号命令归属。
3. SAFE 的唯一明确会话是 `REMOTE 31`。`W38` 完成后必须 `EXIT`，避免将后续 DUT 加热器命令错误发到 SAFE。
4. 125 版有双 main-switch：任何章节若只执行 `W101` 而漏掉 `W295`，都未覆盖原规程的双路要求。
