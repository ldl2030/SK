## 生成基线

- BCM250 详细目录：594 个可执行步骤，覆盖第 7～27 章；91 个判定项；84 个 XML 等待项；6 个始终执行的清理步骤。额外3行是在所有输出关闭后实测并保存DAQ113/117/119分流电阻，后续电流统一按实测电压除以实测阻值计算。

## 映射裁决

优先级：用户确认/仪器映射技能 > 当前工位代码映射 > PDF 的旧 34901/34903 标签。

- DAQ：101(+5V)、102(+VCC)、103(-VEE)、105(MPS.P+/VBUS参考)、106(Gen VBUS+/VMID参考)、107(3V3A)、109(V2)、111(3V3-1)、113(外部分流)、114(String 电压)、117(+5V 分流)、119(+VCC 分流)。
- 分流：+VCC 2.0Ω、+5V 0.4Ω（2026-08-12工位实物确认，替代PDF旧值2.2Ω/0.47Ω）、0.0203111Ω、内部 1Ω、String test 125Ω。
- DAQ 继电器：301(中点)、302(U1.2)、304(2.9/3.3)、305(BOOT0)、318/319(在位检测)。
- 功率继电器：Y3(内部 1Ω)、Y7(RL4)、Y8/Y9/Y10/Y11/Y13/Y15(功率路径)，通过 16 路高功率继电器控制。
- 编程夹具继电器：Y2/Y3/Y4(TTL TX/RX/GND)，通过 8 路夹具继电器控制；不与高功率继电器调用混用。
- BCM250 为单控制器，终端入口使用 `REMOTE2`，不复制 BCM125 的 ST2 分支。

## Hardware 验证门禁

当前未连接仪器，因此以下项目尚未执行，不能记为通过：

1. 确认 TTL 固件文件实际路径和烧录 COM，解除 C01 Hardware 门禁。
2. `LOW_VOLTAGE` 配置默认只启用 PRECHECK、CH07、CLEANUP，先做连接和零输出检查。实际低压输出值需在仪器到场后由工程人员确认，再临时启用目标章节；禁止直接以 CH08 的 275V 动作代替低压验证。
3. 单章节模式逐章启用；涉及 T02 前先确认 DAQ113 的正负端方向。
4. 确认 S02 在 261V 工作点实测合理后，再启用完整流程。
5. 完整流程结束后确认安全监控已取消并等待退出，再检查所有输出、继电器和治具均释放。
