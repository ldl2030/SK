## 双控制器特别规则

- 有 `REMOTE1` / `REMOTE2` 的章节必须分别覆盖 ST1 与 ST2；不得把 BCM-250 单控制器逻辑复用到本板。
- 编程必须逐控制器执行，BCM1 的 RLP4=`@305` 与 BCM2 的 RLP8=`@306` 不能同时作为普通夹具继电器操作。
- 中点、放电、短路、充电、验证、CCB、String test 都需按两路继电器与两套结果号执行；章节结束先关闭负载/电源，再断开功率路径。
