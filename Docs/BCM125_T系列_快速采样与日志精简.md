# BCM125 T系列快速采样与日志精简

最新版本进一步改为T01/T04的30点R44与T02/T05的60点DAQ同窗采集，外部行复用缓存。详见《BCM125_T系列_同窗内部与外部采样》。以下保留前版仅外部固定窗口的实现记录。


2026-10-09，依据15:10复测日志并经用户授权修改。原电流范围、步骤ID与顺序、开启7000ms及关断6000ms等待保持不变。本轮没有控制现场仪器。

## 当前方法

- T02/T05：60点×100ms，1NPLC、1V，固定约6秒窗口；完整采集等待6250ms，配置和批量回读另计。使用真实分流阻值0.0205Ω，所有低谷保留参与有符号均值。启动/稳态/全窗时序、缺点、非法值及过量程校验保持原样，禁止自动重试挑选PASS窗口。
- T03/T06：原6000ms等待后，固定5点R44×200ms，1秒窗口，±20mA不变；当前连接只进行一次事务，失败不重连重读、不平均部分数据。
- 关断通过：不追加DAQ诊断或ADC/补偿寄存器读回。
- 关断NG：保留原R44均值及NG，保持关断工况，追加一次10点×100ms外部分流诊断，再读R42/R50/R56/R22/R23/R24。这些读数在正式R44窗口之后，不声称同步。诊断无效不会改为PASS，取消仍向上传播。DAQ诊断被直接await，停止/恢复完成后才能进入下一步，没有独立后台任务。

## 日志策略

开启通过时保留一条DAQ时序完成摘要与一条电流摘要（点数、平均、极值、低/高值数量、限值），不输出每点数组或重复分流换算，不额外读String电源作通过诊断。其他章节与CCB所需输入检查保持原逻辑。

关断通过时保留一条R44摘要（点数、请求跨度、平均、极值、限值）。普通步骤开始/结束、PASS/NG、变量存储、错误和安全日志继续保留。

开启超限保留完整统计与逐点电压/时间/电流；采集无效保留原始缓存诊断。关断超限保留全部5个R44读数、外部分流10点、系数及ADC诊断；通信/时序异常保留已收样本与错误，不补零或过滤。通过项没有逐点日志，但原始读数仍完整参与正式判定。

完整TestPlatform.sln Debug/Any CPU编译通过。BCM125离线回归通过：956步骤和5个清理步骤、60/100与5/200配置、15:10日志两路各61个60点滑动窗口（每窗保留10个低值、均值起点变化低于0.4mA）、模拟两边开启/关断结果、通过摘要与NG详细诊断、NG数值不可覆盖、缺点/时序/极性/取消/断线检查。
