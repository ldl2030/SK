# SK 四产品共性规则与推广矩阵

适用：BCM-125、BCM-250、MPS-125、MPS-250。更新日期：2026-10-12。

四套已有共同执行框架，但具体实现并不完全一致。本次统一公共规则，保留产品规程差异。

| 项目 | 原有状态 | 统一后的规则 |
|---|---|---|
| 流程执行 | 四套共用 SKBaseSequence，步骤绑定共用 SKBcmSequenceBase | 共用选择、重试、失败策略、取消和安全收尾；XML StepId 与分组校验继续生效 |
| 名称和显示 | BCM-125 的代码名称可能与 XML 名称不同 | 绑定完成后统一采用 XML Name，表格与执行日志显示同名 |
| 日志 | MPS 精简，BCM 仍记录成功 TX 和变量保存等重复信息 | 统一 SKCompactLoggingEnabled；完成行包含通道、StepId、名称、结果、值、范围（有上下限时）、耗时；异常、重试、收尾和 RX 保留 |
| 功率继电器 | 已共用掉电检查、状态复用和单串口会话批量操作 | 继续共用；失败后使涉及状态失效，Modbus 0x06 必须匹配完整回显及 CRC |
| DAQ 继电器 | MPS 逻辑层复用状态，BCM 直接操作时重复下发 | 四套共用物理通道状态；范围、列表、重复项统一解析；只下发需要改变的通道；失败后重新下发；初始化清空状态 |
| MPS 继电器映射 | 两套同样的功能接线各写一份 | 共用 MpsFunctionalRelayMap；产品 StationMap 保留现有访问接口；缺失/错误映射报失败，不能回退到同号站3继电器 |
| MPS 逻辑状态 | DAQ Relay_2 与站3 Y2 等同号对象共用状态字典 | 物理功率与 MPS 逻辑状态分开；直接 DAQ 操作也同步逻辑状态；直接闭合仍检查掉电联锁 |
| MPS 继电器组 | 两套分别循环控制，失败后仍可能继续闭合 | 共用 ControlMpsRelaysAsync；闭合失败停止后续闭合并尝试断开整组；断开失败仍继续其他断开 |
| Heater 稳定等待 | 仅 MPS-125 可在等待中提前测量 | 两套 MPS 共用 SKBaseSequence.Stability；只适用于 CH17 五个指定窗口；不跨写命令、继电器、其他等待边界 |

## 推广边界

共享的是规则和执行机制。BCM 的功率接线、MPS 的逻辑功能接线、烧录控制器数量和测量限值不能直接互相替换。BCM-125 仍使用章节方法组织步骤，其他三套主要使用动作目录；它们通过同一 XML 绑定和执行框架获得本次改进，并未重写产品步骤目录。

DAQ 状态是本设备实例中成功发送命令的记录，不是触点独立回读。通信失败或重新初始化后必须重新建立状态。站1治具下压/释放继续执行自身的安全控制和数字输入到位验证。

Heater 提前结束等待必须满足：参与结果行已选中且 XML 有上下限；经过最短稳定时间；连续两轮完整测量反馈电压合格、电流读数有效；各项变化不超过设定阈值及 XML 范围宽度的 2%。反馈电压和电流共同判稳；稳定但超限的电流可以结束等待，原电流结果仍按 XML 判 NG。完整结果仅在原结果行消费一次；其他动作清除缓存，重试重新测量。两次开启先以 10V 量程单次探测反馈，进入目标范围后再用原 1V 量程和配置采样数完成两轮确认；过渡探测值不能成为正式结果。DAQ 数值无效/超量程时重置连续轮次，在原窗口预算内继续探测；其他异常、超时或持续不满足条件时完成原等待并重新正式测量。取消继续向上传播，所有在途测量完成后才能开始后续 I/O。

BCM 现有实测门禁、同窗采样与并行测量保留各自工况规则。MPS 的 K 系列采样窗口、点火扫描、Chapter 15 缓升时序继续按产品规程执行。

MPS 两套 L06/L10 优先使用原 1V 量程；若数值无效/超量程，则以 10V 量程重新完成同样点数和间隔的平均测量，显示实际反馈并继续按 XML 判定，不把无效值或之前的过渡读数作为结果。若重测反馈不合格，稳定窗口重新回到过渡探测。该回退只适用于 DAQ107/108 的 1V 电压测量，不扩展 BCM 或其他仪器量程。

## 配置与验证

- `SKCompactLoggingEnabled=true`：四套共用精简日志；`false` 恢复开始、成功 TX 和变量保存日志，完成行仍包含统一字段。旧 `SKMPSCompactLoggingEnabled` 只在没有新键时用于 MPS 兼容。
- `SKMPS125HeaterEarlyMeasurementEnabled` / `SKMPS250HeaterEarlyMeasurementEnabled`：各自控制提前测量；关闭后使用原 XML 等待。
- 两套分别使用 `HeaterMinimumSettleMs`、`HeaterStableVoltageDeltaMv`、`HeaterStableCurrentDeltaMa` 配置，当前默认分别为 1000 ms、20 mV、2 mA。
- `Tests/Shared/SkCommonBehaviorTests.cs` 同时链接到四个测试项目，防止某套遗漏共性规则。检查 XML 名称、日志策略、通道归一、重复命令复用、失败状态失效、物理/逻辑隔离及 Modbus 异常/错误回显。
- 两套 MPS 的模拟 DAQ 检查验证 8.9V 过渡、无效值及整批测量失败后的恢复、原 1V 完整测量、缓存仅消费一次、稳定超限电流仍记录 NG，以及持续未就绪时保留原等待和正式测量。四套完整模拟和故障收尾检查仍执行。

验证覆盖软件逻辑和模拟仪器，未操作真实工装；硬件测量效果和触点动作需在对应工装上复核。

2026-10-12 验证结果：Visual Studio MSBuild Debug / Any CPU 构建通过；BCM-125（956 步）、BCM-250（598 步）、MPS-125（231 步）、MPS-250（211 步）四套回归程序均返回 0。新增共性检查、两套 MPS 提前测量及回退检查、完整模拟流程和既有故障收尾检查全部通过。运行配置已由构建同步到输出目录。
