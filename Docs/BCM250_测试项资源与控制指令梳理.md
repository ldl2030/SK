## 强制安全约束

- BCM-250 是**单控制器**；仅使用 `REMOTE2`，不可执行 BCM-125 的 ST2 分支。
- 每次改变 String 路径前，电源 B 必须为 OFF；Y1/Y3/Y6 缺任一闭合不得开启 String 输出。
- C01 的固件文件和 TTL 端口尚需现场确认；未确认时该项只能记录为硬件门禁未解除。
- Q/T 等涉及分流的结果使用第 7 章实测电阻，不能硬编码 PDF 旧阻值。
