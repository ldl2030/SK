每处等待先保留至少1000ms，再按原配置执行完整反馈平均和电流测量。连续两轮所有项目都在各自XML范围内，且同一项目的两轮读数差不超过阈值时，允许提前结束。阈值取“XML范围宽度的2%”与绝对阈值的较小值：电压默认20mV、电流默认2mA；例如L11为50–100mA，允许的轮间变化最多1mA。R71只有开放上限，不能证明目标状态，因此不作为稳定判据，仍在原行读取。

提前成功时复用第二轮的完整测量结果，在原StepId、原结果行记录和保存，避免再做一轮重复采样。缓存仅属于本次运行和当前状态，结果使用一次即移除，任何后续非结果动作都会清空；重测不会沿用旧缓存。测量耗时计入等待行，后面的结果行会记录“复用稳定等待内的完整测量结果”。

XML DelayMs仍为原来的10000ms上限。未稳定、任一项不合格、NaN/无穷大/仪器无效值、完整采样未在预算内完成或探测异常，都不能提前通过。到期丢弃所有探测值，后续结果行按原计划重新测量。探测异常只结束提前尝试，剩余等待仍补足；用户取消和安全取消立即向上层传播，保留原停机/收尾行为。到期时会取消可取消的采样并等待DAQ恢复完成，不遗留后台读操作；正在执行的同步串口查询或恢复可能使实际返回稍晚于上限，不会与正式测量并发。

本轮L11为102.834mA，超过100mA上限。因此即使L10稳定，17.26也不能提前通过。范围和1Ω分流换算保持原值。优化也不保证消除此失败。

第16章K01/K02/K03的真实8秒采样窗口、VBATT放电及电压安全门限、第15章缓升各200ms、15.8的VBATT等待、串口启动及短继电器等待继续保留。短等待若加入两轮完整采样，通常无法节省时间。具体节时取决于实际稳定速度和通信耗时，需用新实机日志确认。
